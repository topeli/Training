# SportScheduleBot

Telegram-бот для расписания тренировок в детско-юношеской спортивной школе.

В спортивной школе расписание и оценки раньше передавались через тренеров и общие чаты, и ученики часто не знали, когда у них тренировка. Мы сделали бота, в котором тренеры составляют расписание, а ученики сразу видят свои занятия и оценки.

## Возможности

Три роли со входом по паролю:

- **ученик** - смотрит свое расписание и оценки, получает уведомления о новых тренировках и оценках;
- **тренер** - добавляет тренировки своим группам (вид спорта, дата, время начала и конца), ставит оценки ученикам;
- **администратор** - регистрирует учеников и тренеров, распределяет группы и виды спорта.

При добавлении тренировки бот предлагает только свободное время, чтобы занятия у тренера и группы не пересекались. За день до тренировки ученикам и тренеру приходит напоминание. Навигация по меню сделана на inline-кнопках с возвратом на предыдущий шаг.

## Стек

Java 19, Spring Boot (Web, Data JPA), PostgreSQL, TelegramBots API, Lombok, Maven. Данные (ученики, тренеры, тренировки, оценки) хранятся в PostgreSQL через JPA, для части данных есть REST-эндпоинты.
